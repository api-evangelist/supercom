# Super.com

> Super.com (formerly SnapTravel and Snapcommerce) is a consumer savings company founded in 2016 by Hussein Fazal and Henry Shi, headquartered in San Francisco. Its app bundles SuperTravel hotel booking, flights, SuperShop savings, SuperCash cash back and credit building, SuperPay, and SuperRx prescription discounts. Its only developer-facing surface is the SnapTravel Partner Search API, a partner-only hotel search-and-book integration. No public API reference or machine-readable specification is published.

This file was generated by API Evangelist from publicly probed surfaces on 2026-08-05. Super.com does not publish an llms.txt of its own (https://www.super.com/llms.txt returns a 403 bot challenge).

## API

- [SnapTravel Partner Search API](https://api.snaptravel.com/): Live host that self-identifies as "Welcome to the Partner Search API for SnapTravel". Hotel search and booking for business partners. Access is by partnership only — there is no public reference, OpenAPI, Swagger, GraphQL SDL, or Postman collection at any Super.com or SnapTravel host.

## Products

- [SuperTravel](https://www.super.com/travel): Hotel search and booking, the company's original SnapTravel product.
- [Flights](https://www.super.com/flights): Flight search and booking.

- [Pay](https://www.super.com/pay): Payments and credit-building card products.

## Security

- [security.txt](https://www.super.com/.well-known/security.txt): RFC 9116 contact file. Security contact is security@super.com; an invite-only Bugcrowd bug bounty program is described but has no public program page.

## Notes for agents

- Every HTML path on www.super.com returns a 403 Cloudflare "Verifying you're human" interstitial to non-browser clients. Plain-text and XML files (robots.txt, sitemap.xml, security.txt) are served normally.
- www.super.com answers unknown /.well-known/* paths with a 307 to /404 rather than a 404. A status-code-only check will read those as hits. They are not.
- No developer, docs, or partner subdomain resolves for super.com. api.snaptravel.com is the only live API host; every documentation path on it returns 404.
- There is no MCP server, A2A agent card, AsyncAPI, webhook catalog, or published SDK for Super.com as of 2026-08-05.
